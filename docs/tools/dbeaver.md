# DBeaver

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `dbeaver`

## Что это

Универсальный GUI-клиент для SQL и NoSQL баз данных.

## Зачем нужен

Один инструмент для Postgres, MySQL, SQLite, и многих других.

## Примеры

```bash
dbeaver-ce   # или dbeaver
```

## Установка через CLI Toolbox

```bash
./install.sh --only dbeaver
./install.sh --update --only dbeaver
```

Определение пакета: [`catalog/tools/dbeaver.yaml`](../../catalog/tools/dbeaver.yaml).
