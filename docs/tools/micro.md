# micro

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `micro`

## Что это

Простой терминальный редактор с привычными Ctrl+C/V/S/Q.

## Зачем нужен

Легче nano/vim для быстрых правок конфигов.

## Примеры

```bash
micro ~/.zshrc
```

## Установка через CLI Toolbox

```bash
./install.sh --only micro
./install.sh --update --only micro
```

Определение пакета: [`catalog/tools/micro.yaml`](../../catalog/tools/micro.yaml).
