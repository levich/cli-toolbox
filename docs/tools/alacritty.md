# Alacritty

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `alacritty`

## Что это

Кроссплатформенный GPU-ускоренный эмулятор терминала.

## Зачем нужен

Высокая производительность, конфигурация через YAML.

## Примеры

```bash
alacritty
# конфиг: ~/.config/alacritty/alacritty.toml
```

## Установка через CLI Toolbox

```bash
./install.sh --only alacritty
./install.sh --update --only alacritty
```

Определение пакета: [`catalog/tools/alacritty.yaml`](../../catalog/tools/alacritty.yaml).
