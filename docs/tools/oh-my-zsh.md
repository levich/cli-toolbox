# Oh My Zsh

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `oh-my-zsh`

## Что это

Фреймворк для управления конфигурацией zsh: плагины, темы, удобные алиасы.

## Зачем нужен

Быстрый старт с сотнями плагинов (git, fzf, docker и др.) без ручной настройки.

## Примеры

```bash
# Плагины в ~/.zshrc:
plugins=(git fzf zoxide)
```

## Установка через CLI Toolbox

```bash
./install.sh --only oh-my-zsh
./install.sh --update --only oh-my-zsh
```

Определение пакета: [`catalog/tools/oh-my-zsh.yaml`](../../catalog/tools/oh-my-zsh.yaml).
