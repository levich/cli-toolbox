# Insomnia

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `insomnia`

## Что это

HTTP-клиент для проектирования и отладки REST/GraphQL API.

## Зачем нужен

Коллекции запросов, окружения и авторизация без Postman.

## Примеры

```bash
# Запускается из меню приложений / insomnia
```

## Установка через CLI Toolbox

```bash
./install.sh --only insomnia
./install.sh --update --only insomnia
```

Определение пакета: [`catalog/tools/insomnia.yaml`](../../catalog/tools/insomnia.yaml).
