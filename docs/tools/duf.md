# duf

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `duf`

## Что это

Красивая таблица свободного места на дисках/разделах (замена df).

## Зачем нужен

Быстро понять, куда упирается место.

## Примеры

```bash
duf
duf --only local
```

## Установка через CLI Toolbox

```bash
./install.sh --only duf
./install.sh --update --only duf
```

Определение пакета: [`catalog/tools/duf.yaml`](../../catalog/tools/duf.yaml).
