# nvtop

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `nvtop`

## Что это

Интерактивный TUI-монитор GPU (NVIDIA, AMD, Intel) в духе htop/btop.

## Зачем нужен

Смотреть загрузку GPU, память и процессы на машинах с видеоускорителями.

## Примеры

```bash
nvtop
```

## Установка через CLI Toolbox

```bash
./install.sh --only nvtop
```

Определение: [`catalog/tools/nvtop.yaml`](../../catalog/tools/nvtop.yaml).
