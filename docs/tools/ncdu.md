# ncdu

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `ncdu`

## Что это

Интерактивный анализатор занятого места (ncurses du).

## Зачем нужен

Найти тяжёлые каталоги и быстро почистить диск.

## Примеры

```bash
ncdu /
ncdu ~
```

## Установка через CLI Toolbox

```bash
./install.sh --only ncdu
./install.sh --update --only ncdu
```

Определение пакета: [`catalog/tools/ncdu.yaml`](../../catalog/tools/ncdu.yaml).
