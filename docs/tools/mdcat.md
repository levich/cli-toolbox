# mdcat

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `mdcat`

## Что это

Рендер Markdown прямо в терминале.

## Зачем нужен

Читать README без открытия браузера/редактора.

## Примеры

```bash
mdcat README.md
```

## Установка через CLI Toolbox

```bash
./install.sh --only mdcat
```

Определение: [`catalog/tools/mdcat.yaml`](../../catalog/tools/mdcat.yaml).
