# lazydocker

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `lazydocker`

## Что это

TUI для Docker и Compose.

## Зачем нужен

Логи, контейнеры и образы без длинных docker-команд.

## Примеры

```bash
lazydocker
```

## Установка через CLI Toolbox

```bash
./install.sh --only lazydocker
```

Определение: [`catalog/tools/lazydocker.yaml`](../../catalog/tools/lazydocker.yaml).
