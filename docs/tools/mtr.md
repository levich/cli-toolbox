# mtr

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `mtr`

## Что это

Комбинация traceroute и ping с интерактивным выводом.

## Зачем нужен

Диагностика сетевого пути и потерь пакетов.

## Примеры

```bash
mtr example.com
mtr -r -c 10 example.com
```

## Установка через CLI Toolbox

```bash
./install.sh --only mtr
```

Определение: [`catalog/tools/mtr.yaml`](../../catalog/tools/mtr.yaml).
