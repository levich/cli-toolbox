# Postman

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `postman`

## Что это

Платформа для API: запросы, коллекции, моки, тесты.

## Зачем нужен

Стандарт de-facto для совместной работы над API.

## Примеры

```bash
# postman или приложение Postman
```

## Установка через CLI Toolbox

```bash
./install.sh --only postman
./install.sh --update --only postman
```

Определение пакета: [`catalog/tools/postman.yaml`](../../catalog/tools/postman.yaml).
