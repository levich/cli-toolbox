# lazygit

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `lazygit`

## Что это

Интерактивный TUI для повседневных git-операций.

## Зачем нужен

Статейджинг, коммиты, rebase и ветки без длинных команд.

## Примеры

```bash
lazygit
```

## Установка через CLI Toolbox

```bash
./install.sh --only lazygit
./install.sh --update --only lazygit
```

Определение пакета: [`catalog/tools/lazygit.yaml`](../../catalog/tools/lazygit.yaml).
