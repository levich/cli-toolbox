# wget

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `wget`

## Что это

Загрузка файлов и зеркалирование сайтов.

## Зачем нужен

Надёжные докачки и рекурсивные загрузки.

## Примеры

```bash
wget -c URL
wget -m -p -E -k URL
```

## Установка через CLI Toolbox

```bash
./install.sh --only wget
```

Определение: [`catalog/tools/wget.yaml`](../../catalog/tools/wget.yaml).
