# Midnight Commander

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `mc`

## Что это

Классический двухпанельный файловый менеджер в терминале.

## Зачем нужен

Копирование, сравнение и просмотр архивов без выхода в GUI.

## Примеры

```bash
mc
```

## Установка через CLI Toolbox

```bash
./install.sh --only mc
./install.sh --update --only mc
```

Определение пакета: [`catalog/tools/mc.yaml`](../../catalog/tools/mc.yaml).
