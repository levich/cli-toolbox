# Visual Studio Code

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `code`

## Что это

Популярный редактор кода с расширениями и встроенным Git/Debug.

## Зачем нужен

Универсальная GUI-среда разработки; remote/WSL хорошо поддерживаются.

## Примеры

```bash
code .
code --install-extension ms-python.python
```

## Установка через CLI Toolbox

```bash
./install.sh --only code
./install.sh --update --only code
```

Определение пакета: [`catalog/tools/code.yaml`](../../catalog/tools/code.yaml).
