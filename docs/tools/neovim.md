# Neovim

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `neovim`

## Что это

Форк Vim с Lua API, LSP и асинхронными плагинами.

## Зачем нужен

Современная IDE-подобная среда прямо в терминале.

## Примеры

```bash
nvim file.txt
nvim +Mason
```

## Установка через CLI Toolbox

```bash
./install.sh --only neovim
./install.sh --update --only neovim
```

Определение пакета: [`catalog/tools/neovim.yaml`](../../catalog/tools/neovim.yaml).
