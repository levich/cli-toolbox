# btop

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `btop`

## Что это

Красивый ресурс-монитор (CPU, RAM, диски, сеть) с мышью и темами.

## Зачем нужен

Наглядная альтернатива htop/top.

## Примеры

```bash
btop
```

## Установка через CLI Toolbox

```bash
./install.sh --only btop
./install.sh --update --only btop
```

Определение пакета: [`catalog/tools/btop.yaml`](../../catalog/tools/btop.yaml).
