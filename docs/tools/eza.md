# eza

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `eza`

## Что это

Современная замена `ls` с цветами, иконками, git-статусом и деревом.

## Зачем нужен

Читаемый листинг каталогов «из коробки».

## Примеры

```bash
eza -la
eza --tree --level=2
eza --git
```

## Установка через CLI Toolbox

```bash
./install.sh --only eza
./install.sh --update --only eza
```

Определение пакета: [`catalog/tools/eza.yaml`](../../catalog/tools/eza.yaml).
