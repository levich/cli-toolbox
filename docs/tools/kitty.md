# kitty

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `kitty`

## Что это

Быстрый терминал с вкладками, изображениями и скриптами (kittens).

## Зачем нужен

Богатый функционал при сохранении скорости.

## Примеры

```bash
kitty
kitten icat image.png
```

## Установка через CLI Toolbox

```bash
./install.sh --only kitty
./install.sh --update --only kitty
```

Определение пакета: [`catalog/tools/kitty.yaml`](../../catalog/tools/kitty.yaml).
