# curl

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `curl`

## Что это

Универсальный клиент URL (HTTP и многое другое).

## Зачем нужен

Основа скриптов и API-вызовов; часто уже есть в системе.

## Примеры

```bash
curl -fsSL URL
curl -I URL
```

## Установка через CLI Toolbox

```bash
./install.sh --only curl
```

Определение: [`catalog/tools/curl.yaml`](../../catalog/tools/curl.yaml).
