# GitHub CLI

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `gh`

## Что это

Официальный CLI GitHub: PR, issues, checks, релизы.

## Зачем нужен

Работать с GitHub не выходя из терминала.

## Примеры

```bash
gh auth login
gh pr create
gh pr checks
```

## Установка через CLI Toolbox

```bash
./install.sh --only gh
```

Определение: [`catalog/tools/gh.yaml`](../../catalog/tools/gh.yaml).
