# git

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `git`

## Что это

Распределённая система контроля версий.

## Зачем нужен

Основа современной разработки ПО.

## Примеры

```bash
git status
git clone <url>
git log --oneline --graph
```

## Установка через CLI Toolbox

```bash
./install.sh --only git
./install.sh --update --only git
```

Определение пакета: [`catalog/tools/git.yaml`](../../catalog/tools/git.yaml).
