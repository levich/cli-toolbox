# 7-Zip

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `7zip`

## Что это

Кроссплатформенный архиватор с высокой степенью сжатия. Команды: `7z`, `7zz` или `7za`.

## Зачем нужен

Работа с `.7z`, `.zip`, `.tar`, `.gz` и многими другими форматами из CLI.

## Примеры

```bash
7z x archive.7z
7z a backup.7z ./data
7z l archive.zip
```

## Установка через CLI Toolbox

```bash
./install.sh --only 7zip
```

Определение: [`catalog/tools/7zip.yaml`](../../catalog/tools/7zip.yaml).
