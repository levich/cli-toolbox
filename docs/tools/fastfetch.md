# fastfetch

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `fastfetch`

## Что это

Быстрый вывод информации о системе (как neofetch, но быстрее).

## Зачем нужен

Диагностика окружения и «скриншот» конфигурации машины.

## Примеры

```bash
fastfetch
fastfetch --logo none
```

## Установка через CLI Toolbox

```bash
./install.sh --only fastfetch
./install.sh --update --only fastfetch
```

Определение пакета: [`catalog/tools/fastfetch.yaml`](../../catalog/tools/fastfetch.yaml).
