# topgrade

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `topgrade`

## Что это

Одна команда обновляет пакеты всех менеджеров (brew, apt, cargo, oh-my-zsh…).

## Зачем нужен

Меньше рутины при поддержке «швейцарского ножа» из утилит.

## Примеры

```bash
topgrade
topgrade --dry-run
```

## Установка через CLI Toolbox

```bash
./install.sh --only topgrade
./install.sh --update --only topgrade
```

Определение пакета: [`catalog/tools/topgrade.yaml`](../../catalog/tools/topgrade.yaml).
