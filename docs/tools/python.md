# Python

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `python`

## Что это

Интерпретатор языка Python 3 — стандартная среда для скриптов, автоматизации и разработки.

## Зачем нужен

База для инструментов вроде pip, многих CLI и собственных скриптов. На macOS через Homebrew ставится актуальный Python 3; на Linux — пакет `python3` дистрибутива.

## Примеры

```bash
python3 --version
python3 -c 'print("hello")'
python3 script.py
```

## Установка через CLI Toolbox

```bash
./install.sh --only python
./install.sh --update --only python
```

Определение пакета: [`catalog/tools/python.yaml`](../../catalog/tools/python.yaml).
