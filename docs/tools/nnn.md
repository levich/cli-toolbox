# nnn

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `nnn`

## Что это

Очень лёгкий и быстрый файловый менеджер для терминала.

## Зачем нужен

Минимум зависимостей, плагины, работа по SSH.

## Примеры

```bash
nnn
nnn -e
```

## Установка через CLI Toolbox

```bash
./install.sh --only nnn
./install.sh --update --only nnn
```

Определение пакета: [`catalog/tools/nnn.yaml`](../../catalog/tools/nnn.yaml).
