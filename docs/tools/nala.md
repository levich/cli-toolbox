# nala

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `nala`

## Что это

Дружелюбный фронтенд к apt с параллельной загрузкой и понятным выводом.

## Зачем нужен

Удобнее обычного apt на Ubuntu/Debian.

## Примеры

```bash
sudo nala update
sudo nala install htop
nala history
```

## Установка через CLI Toolbox

```bash
./install.sh --only nala
./install.sh --update --only nala
```

Определение пакета: [`catalog/tools/nala.yaml`](../../catalog/tools/nala.yaml).
