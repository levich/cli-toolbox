# Cursor

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `cursor`

## Что это

Редактор на базе VS Code с глубокой интеграцией AI-агента.

## Зачем нужен

Ускоряет написание и рефакторинг кода с контекстом репозитория.

## Примеры

```bash
cursor .
```

## Установка через CLI Toolbox

```bash
./install.sh --only cursor
./install.sh --update --only cursor
```

Определение пакета: [`catalog/tools/cursor.yaml`](../../catalog/tools/cursor.yaml).
