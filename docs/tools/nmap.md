# nmap

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `nmap`

## Что это

Сканер хостов и портов.

## Зачем нужен

Инвентаризация сети и проверка сервисов (только свои системы).

## Примеры

```bash
nmap -sV 192.168.1.1
nmap -sn 192.168.1.0/24
```

## Установка через CLI Toolbox

```bash
./install.sh --only nmap
```

Определение: [`catalog/tools/nmap.yaml`](../../catalog/tools/nmap.yaml).
