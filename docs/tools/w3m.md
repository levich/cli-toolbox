# w3m

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `w3m`

## Что это

Текстовый (TUI) веб-браузер.

## Зачем нужен

Открыть документацию и HTML на сервере без GUI.

## Примеры

```bash
w3m https://example.com
w3m ./index.html
```

## Установка через CLI Toolbox

```bash
./install.sh --only w3m
```

Определение: [`catalog/tools/w3m.yaml`](../../catalog/tools/w3m.yaml).
