# htop

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `htop`

## Что это

Интерактивный монитор процессов.

## Зачем нужен

Классика рядом с btop; часто доступен везде.

## Примеры

```bash
htop
```

## Установка через CLI Toolbox

```bash
./install.sh --only htop
```

Определение: [`catalog/tools/htop.yaml`](../../catalog/tools/htop.yaml).
