# delta

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `delta`

## Что это

Подсветка и пагинация git-diff.

## Зачем нужен

Читаемые диффы в терминале и вместе с lazygit.

## Примеры

```bash
git diff | delta
# настройка pager в ~/.gitconfig
```

## Установка через CLI Toolbox

```bash
./install.sh --only delta
```

Определение: [`catalog/tools/delta.yaml`](../../catalog/tools/delta.yaml).
