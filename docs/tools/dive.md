# dive

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `dive`

## Что это

Интерактивный анализ слоёв Docker-образа.

## Зачем нужен

Найти, что раздувает image и где лишние файлы.

## Примеры

```bash
dive myimage:tag
```

## Установка через CLI Toolbox

```bash
./install.sh --only dive
```

Определение: [`catalog/tools/dive.yaml`](../../catalog/tools/dive.yaml).
