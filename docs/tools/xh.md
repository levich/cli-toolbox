# xh

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `xh`

## Что это

Дружелюбный HTTP-клиент, совместимый по духу с HTTPie.

## Зачем нужен

Удобные запросы к API из терминала и SSH.

## Примеры

```bash
xh httpbin.org/get
xh POST httpbin.org/post name=Ada
```

## Установка через CLI Toolbox

```bash
./install.sh --only xh
```

Определение: [`catalog/tools/xh.yaml`](../../catalog/tools/xh.yaml).
