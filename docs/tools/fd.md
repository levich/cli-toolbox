# fd

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `fd`

## Что это

Быстрый и удобный поиск файлов (альтернатива find).

## Зачем нужен

Игнорирует .gitignore, понятный синтаксис, скорость.

## Примеры

```bash
fd README
fd -e go
fdfind pattern   # Debian/Ubuntu
```

## Установка через CLI Toolbox

```bash
./install.sh --only fd
```

Определение: [`catalog/tools/fd.yaml`](../../catalog/tools/fd.yaml).
