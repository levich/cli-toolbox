# atuin

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `atuin`

## Что это

История shell с поиском и опциональной синхронизацией.

## Зачем нужен

Сильнее обычного Ctrl-R; удобно между машинами.

## Примеры

```bash
eval "$(atuin init zsh)"
atuin import auto
```

## Установка через CLI Toolbox

```bash
./install.sh --only atuin
```

Определение: [`catalog/tools/atuin.yaml`](../../catalog/tools/atuin.yaml).
