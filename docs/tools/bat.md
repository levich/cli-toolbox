# bat

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `bat`

## Что это

Просмотр файлов как `cat`, но с подсветкой, git-диффом и пейджингом.

## Зачем нужен

Удобнее читать код и логи в терминале.

## Примеры

```bash
bat README.md
bat -A file.txt
```

## Установка через CLI Toolbox

```bash
./install.sh --only bat
./install.sh --update --only bat
```

Определение пакета: [`catalog/tools/bat.yaml`](../../catalog/tools/bat.yaml).
