# zsh

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `zsh`

## Что это

Zsh (Z shell) — интерактивная командная оболочка с мощным автодополнением, историей и скриптингом.

## Зачем нужен

База для Oh My Zsh и Powerlevel10k; удобнее bash для повседневной работы в терминале.

## Примеры

```bash
zsh
chsh -s $(which zsh)
```

## Установка через CLI Toolbox

```bash
./install.sh --only zsh
./install.sh --update --only zsh
```

Определение пакета: [`catalog/tools/zsh.yaml`](../../catalog/tools/zsh.yaml).
