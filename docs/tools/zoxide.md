# zoxide

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `zoxide`

## Что это

Умный `cd`: прыжки в часто/недавно посещённые каталоги.

## Зачем нужен

Меньше полного ввода длинных путей.

## Примеры

```bash
eval "$(zoxide init zsh)"  # в ~/.zshrc
z proj
zi   # интерактивно (с fzf)
```

## Установка через CLI Toolbox

```bash
./install.sh --only zoxide
./install.sh --update --only zoxide
```

Определение пакета: [`catalog/tools/zoxide.yaml`](../../catalog/tools/zoxide.yaml).
