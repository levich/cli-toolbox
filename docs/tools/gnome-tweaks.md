# GNOME Tweaks

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `gnome-tweaks`

## Что это

Панель тонкой настройки рабочего стола GNOME.

## Зачем нужен

Шрифты, анимации, кнопки окна, расширения — то, чего нет в стандартных Настройках.

## Примеры

```bash
gnome-tweaks
```

## Установка через CLI Toolbox

```bash
./install.sh --only gnome-tweaks
./install.sh --update --only gnome-tweaks
```

Определение пакета: [`catalog/tools/gnome-tweaks.yaml`](../../catalog/tools/gnome-tweaks.yaml).
