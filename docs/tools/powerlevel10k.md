# Powerlevel10k

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `powerlevel10k`

## Что это

Тема для zsh с мгновенным рендером prompt и мастером настройки `p10k configure`.

## Зачем нужен

Информативный prompt (git, время, статус) без ощутимых задержек.

## Примеры

```bash
p10k configure
```

## Установка через CLI Toolbox

```bash
./install.sh --only powerlevel10k
./install.sh --update --only powerlevel10k
```

Определение пакета: [`catalog/tools/powerlevel10k.yaml`](../../catalog/tools/powerlevel10k.yaml).
