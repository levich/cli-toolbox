# asciinema

**Категория:** см. [оглавление](../index.md) · **ID в каталоге:** `asciinema`

## Что это

Запись терминальных сессий в файл .cast.

## Зачем нужен

Демо, багрепорты, обучение.

## Примеры

```bash
asciinema rec demo.cast
asciinema play demo.cast
```

## Установка через CLI Toolbox

```bash
./install.sh --only asciinema
```

Определение: [`catalog/tools/asciinema.yaml`](../../catalog/tools/asciinema.yaml).
